# Social Media Engagement Analytics

A SQL-based data analytics project focused on exploring social media engagement, user activity, trending hashtags, influencer performance and posting patterns.

## Project Dashboard

**Live Website:**

## Tools Used

- SQL – Data analysis and querying
- HTML, CSS and JavaScript – Website development
- AI tools – Used to create the interactive website and dashboard
- GitHub Pages – Website hosting

## About the Website

The interactive website and dashboard were developed with the assistance of AI tools. AI was used to generate the HTML, CSS and JavaScript code, as I do not have prior experience in these technologies.

## Dataset

The project uses a synthetic, AI-generated dataset for educational and analytical purposes. The findings do not represent actual social media platform statistics.
